이화여대 「AI와 비즈니스 애플리케이션」 수업에서 4팀이 함께 진행한 작업물을 모아둔 공간입니다.
생성형 AI를 활용한 발표자료와 AI 기반 웹 앱을 정리했습니다.

## 🎤 바이브 코딩 발표자료
한국어 위키백과 "바이브 코딩" 문서를 바탕으로 만든 HTML 발표자료입니다. 전체 화면 모드에서 슬라이드 쇼로 진행됩니다.

👉 https://toby0033-afk.github.io/vibe-coding-2026-team/

## 📂 팀 작업물 목록

### 1. No Pressure — 발표 긴장 시뮬레이션 앱
발표 대본을 입력하면 AI가 교수님 질문, 청중 반응, 끊길 위험 구간, 돌발 상황을 시뮬레이션하여 실전 발표를 연습하도록 돕는 앱입니다.
- 폴더: `no-pressure/`
- 앱 링크: https://ai.studio/apps/18d366cd-3948-4f9a-83f1-740f02bf1e61

### 2. Rubric Detective — 과제 PDF 분석 앱
과제 안내문·강의계획서·평가 루브릭 등의 PDF를 채점자 관점에서 분석하여, 숨은 평가 기준과 감점 위험 요소, 제출 전 체크리스트를 찾아주는 앱입니다.
- 폴더: `rubric-detective/`
- 앱 링크: https://aistudio.google.com/apps/6f0716ba-3707-4944-a5cb-c063399309e2
